# Setup-скрипт

Описание: cкрипт принимает аргумент (имя пользователя), создаёт директорию, файл .bashrc, выдаёт приветствие и записывает факт создания в лог.

## Выдача прав

Перед запуском скрипта на машине нужно выполнить команду:

```sh
chmod +x script.sh
```

Это позволит нашему скрипту быть исполняемым.

## Пример использования

Команда:

```sh
./script.sh alex
```

Вывод:

```sh
Привет, alex!
Создан каталог: /home/ubuntu/sysadmin-users/alex
```
